# Mùa Nước Nổi — MVP

Prototype game 2D top-down về đời sống xã Phú Lâm và vùng Phú Tân cũ, tỉnh An Giang, được tích hợp tại:

```text
http://localhost:5173/mua-nuoc-noi
```

Khởi chạy:

```bash
npm install
npm run dev
```

Điều khiển bằng `WASD` hoặc phím mũi tên; nhấn `E` để tương tác. Trên thiết bị cảm ứng, dùng cụm phím điều hướng trên màn hình. Tiến trình được lưu tự động trong `localStorage` với khóa `muanuocnoi-save`.

Vertical slice hiện có: bản đồ và camera theo nhân vật, collision, NPC, nhiệm vụ, chuỗi canh tác, chợ mua/bán, túi đồ, việc làm, gia đình, chat mô phỏng, chu kỳ ngày mới, thời tiết và mực nước.

Website chính: https://tattantat67k1.web.app/
